# Study Tracker – Python Project

A personal study-time tracking application developed using Python. This program allows users to organize their study schedules, manage tasks, track study sessions with a built-in timer, and record completed activities.

The application uses Python dictionaries to manage tasks and JSON files to store study history, allowing users to review their daily and overall study progress.

**Key Features:**
- Add and delete study tasks.
- Set planned study durations.
- Execute tasks with a built-in countdown timer.
- Record actual study time.
- View pending and completed tasks.
- Save study records using JSON.
- Calculate daily and total study time.

**Technologies:** Python, JSON, `datetime`, `time`, and `os`.

**Purpose:** To practise Python programming concepts, including functions, dictionaries, loops, conditional statements, exception handling, and file management, while building a practical productivity tool.
